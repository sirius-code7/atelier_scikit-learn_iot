# Atelier Seaborn IoT

Atelier sur Seaborn qui est une bibliothèque de visualisation de données en Python construite au-dessus de Matplotlib, sur l'analyse de données issues de capteurs IoT.

## Structure

```
atelier_seaborn_iot/
│
├── data/
├── notebooks/
└── exports/
```

Le projet est organisé en plusieurs dossiers afin de séparer les données, le notebook de travail et les graphiques exportés.

Cette organisation facilite le développement, la maintenance et la réutilisation du projet.
